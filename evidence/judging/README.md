# Figures and fresh inference for judging

[Read the final judging report](../../docs/Final_MedgeVision_Report.pdf).

These five image pairs were generated by calling the shipped application detector and anomaly engine with the repository's frozen ONNX models. The selected inputs illustrate outputs. Accuracy and Pi runtime results come from the separately recorded experiments.

- YOLOv8s FP32 CPU: [crack bounding box](yolo_crack_boxes.png) and [empty pocket bounding boxes](yolo_empty_boxes.png).
- EfficientAD-S CPU: [MVTec pill](mvtec_pill_heatmap.png), [MVTec capsule](mvtec_capsule_heatmap.png), and [VisA capsules](visa_capsules_heatmap.png). Each panel uses its own profile thresholds and fixed color scale.
- The [inference receipt](inference_receipt.json) records input and output SHA-256, model identity, detections, anomaly scores, and thresholds.

## Reproduce

From the repository root after [CPU setup](../../QUICKSTART.md):

```sh
python tools/generate_judging_examples.py --output /path/to/new-output
```

Install Matplotlib in the development environment and add `--figures` to regenerate the five plots. The script writes new results to the chosen directory. Numerical outputs and image encoding can vary slightly across platforms and dependency builds.
