## Remaining acceptance limits

- Physical Pi browser60fps zoom/pan/loupe and long-shift endurance require target-panel
  measurement. Headless desktop rendering against a Pi API is not target rendering.
- Governor sustained-load Pi device testing remains outstanding.
- No claim of formal WCAG certification, measured zero cumulative layout shift,
  photo-sensitive safety certification, or complete keyboard/screen-reader audit.
  Status colors have icon/label alternatives, focus rings and native modal trapping.
- Camera frame age, exact per-stage progress, live token rate/streaming, batch targets,
  authentication and server audit verification need separate backend contracts.
- Demo chain verification is browser-generated, not proof of backend database integrity.
- Decorative geometric iris and uniform bbox reveal are restrained interpretations.
  Independent corner drawing, magnetic hover, shared-thumbnail morphs and milestones
  are not implemented. These do not affect inspection or advisory behavior.
