## Instrumentation and experiments

The separate `blistertrace_instrumented` worker preserves baseline binary/artifacts. The framed protocol adds STATS before OK and records model-load time, tokenization, prefill, first-token, total generation and counts. Raw timestamps permit decode throughput to be computed from generated tokens after the first token over the decode interval. No token rate is derived from total advisory time. JSON budgeting and full model load are distinct from native generation.

The worker persists across jobs, temperature0, bounded output, independent KV reset, one worker and one waiting job. Cache identity includes model hash, SOP revision/hash, prompt mode/version, output budget and evidence. Errors/cancellation terminate damaged workers; subsequent work can start a fresh process. Full4-thread priority/overclocking was not forced. Three production threads preserve scheduling capacity for HailoRT/API/SQLite; see measured matrix before changing this.

The zero-shot compact-v1 returned prose; compact-v2 copied extra/input fields and was stopped early after15poor trials. Neither was selected. The one-relevant-example **adaptive-v1** prompt completed the paired50-case comparison with37/39accepted under the experimental guards; replay through the final stricter chemical/microbial-claim guards accepted36/39, compared with26/39for the baseline. It is selected for demonstration with128output tokens and3CPUthreads. The old prompt/192budget remains reversible. Human semantic scoring and approved procedures remain unavailable.

The final native worker stops decoding when the first top-level JSON object closes, respecting quoted/escaped braces. This prevents additional unsolicited objects after the requested response. It does not turn prose into JSON or bypass schema/claim checks. Five native boundary tests and fresh target generation verify the behavior. Earlier paired benchmark timings predate this final boundary optimization; they are retained as measured rather than relabelled as fresh timings. New application checks record actual final-worker timings separately.
